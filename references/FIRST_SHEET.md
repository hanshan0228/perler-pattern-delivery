# 首稿质量规范 / First-sheet quality contract (v2.6)

## 目标与输入分流

- 默认交付：卡通人物 **带色号单页拼豆图纸**，不是画一张看起来像网格的图。若用户明确指定写实，运行 `prepare --mode photo` 且不提供 `--cartoon-image`；如果同时请求两版，分开审核及交付；若指定像素图，按指定走；只请求底图/模拟效果时才单独交付底图/模拟图。
- 新肖像默认 87×87、最多 33 个 MARD 颜色（不是必须恰好 33 个）。58×58 可作为小尺寸备选，不擅自缩小用户指定尺寸。
- 已确认 MASTER 永远优先；新造型才重新生成。任何卡通源或客户原始照片只留在客户项目目录，不上传到公共 GitHub。

## 图像生成提示词（作为实际图像编辑任务，不是文本替代品）

> Edit the supplied photo into a clean, bust-length, precise hand-drawn flat-color cartoon portrait for a fuse-bead chart. Preserve pose, gaze, recognizable facial proportions, eye shape, expression, hairstyle silhouette, clothing and distinctive accessories. Make the face and important features large enough to remain readable at 87 by 87 pixels. Use broad contiguous flat color regions, 2–3 shades per main skin/hair/clothing region, controlled thin dark outlines only where useful, clearly separated eyes and mouth, simplified but recognizable accessories. Use a square composition, centered subject, keep the entire important silhouette and accessories inside the frame, plain warm ivory background. Avoid photographic texture, complex background, hair-by-hair rendering, excessive shading, gradients, tiny decorative specks and thick black contours. No grid, no bead texture, no color codes, no text, no legend. The exact MARD grid and legend will be generated by separate code.

Adjust important features to actual photo (not all subjects have flowers). Do not simply run smoothing/edge filters and call the result AI. Do not generate the final numbered chart with an image-generation model. An agent that lacks image-editing capability must request an actual cartoon source rather than switch to a visually inferior hidden fallback.

## Visual review (required before first user-visible chart)

Inspect the original, cartoon base and all five candidate previews at thumbnail and full-size. Compare against approved style benchmark generated from `examples/approved_87x87.csv` (33 colors, 7569 beads, digest `8c7bcbb1ad12ac1257b38c89496b1924f93fb40cc06a50c7859d1d2b201e6fc5`). It is a **style** reference — never replace the new customer's subject with it. The user-approved 58×58 benchmark also remains unchanged.

The five fields in the review JSON mean:

- `recognizable_subject`: actual original pose, major facial features and expression are retained; not a generic substitute.
- `cartoon_not_photo_filter`: intentional illustration with coherent flat-color areas; not a smoothed photo.
- `framing_and_silhouette`: important silhouette, accessories and hair remain in frame; composition fills the board appropriately.
- `key_features_readable`: eyes, mouth, eyebrows, face contour, clothing/accessories read at actual bead resolution. No disconnected essential features.
- `clean_regions_and_no_artifacts`: no unintended speckles, dark grid seams, distracting text-like objects, accidental gradients or disproportionately noisy regions. Do not sacrifice essential one-cell details just to reduce noise.

Use concrete notes stating what was inspected and why the selected variant wins. If either cartoon stage or all variants fail, regenerate base (or revise palette/resolution only if allowed) in new folder and rerun. At most two corrective rounds per task. No falsely marked pass or pretend visual review. Preserve every approved matrix. If review cannot be performed, state that and stop; a hash is not aesthetic validation.

## Deterministic rendering and acceptance

`prepare` pads rather than silently cropping an important silhouette, produces five candidates (central median, area average, MARD-constrained portrait, regional palette refinement, and spatially coherent refinement) and a review sheet. The portrait variant has a conservative cleanup pass outside designated focus regions and source edges; the other two variants are unchanged. `select` requires review bound to the selected matrix digest and actual comparison image; its `candidate_sheet.png` is explicitly unapproved. `verify` checks required files, pinned palette, matrix and semantic pixels, exact color counts, legend and file hashes. It cannot certify aesthetic quality or that a human actually looked at the images. User confirmation triggers existing `freeze` and `deliver`; never auto-approve the candidate.

## Final user response

Lead with the selected candidate sheet; include a link to the high-resolution sheet and optionally matrix and zoomable chart. Briefly state grid, number of colors, beads, boards, validation and unapproved status. Do not present competing weak drafts to the customer unless requested. Do not present the original reference comparison as the main deliverable.

## 最终图纸反幻觉门禁（v2.4）

- `select` 新增 A2 单页 PDF；PNG、PDF 与 CSV 必须来自同一矩阵。`verify` 重新渲染实际带坐标、每格色号和图例的 PNG；以确定性 PDF 重新生成并比较，拒绝仅更新哈希的假图纸。固定 MARD 色卡与仓库参考表匹配。
- `--mode photo` 使用 `realistic_not_cartoon` 替代 `cartoon_not_photo_filter`，其余视觉检查相同；模式记录在候选清单中。
- 禁止用生成式模型直接画施工图，即使用户说“直接给我图纸”。只可用它生成艺术底图。没有本地执行能力就明确说明限制。
- 重渲染验证针对同一可信代码与运行环境，不是对任意第三方截图的 OCR 认证，也不是不可伪造的数字签名或自动审美评价。

## v2.6 portrait variant

Use `--focus x0 y0 x1 y1` (repeatable, normalized coordinates of the padded square stage) only after inspecting the actual artwork. This is a manual region, not a face detector. Pixel selection is constrained to actual MARD reference colors and the requested maximum color count; high-contrast edges and focus regions receive greater weight. Cleanup never changes cells within focus rectangles or above the source contrast threshold. Compare actual previews, actual color counts, ΔE76 diagnostics and isolated-cell counts. Do not auto-select the lowest-error variant; more colors can increase complexity and isolated cells. All five variants use the same immutable delivery and review gates.

## v2.6 spatial/region candidates

`regional` uses up to two bounded palette swaps from `portrait`, requiring the same actual number of in-use colors, lower weighted RMS error, and no increase in focus/edge mean error. `coherent` uses the very same palette as `portrait`, freezes focus/strong-edge cells and reduces unnecessary flat-region boundaries within per-cell and global error caps; reverts if isolation increases or flat-region boundaries do not decrease. Both may be identical to the base candidate. Review all five, the user-approved style benchmark, and diagnostic Pareto set; no automatic aesthetic winner. All reports are recomputed for new v4 prepared manifests.
